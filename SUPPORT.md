# Support

Community support is provided through public repository issues on a reasonable-effort basis. Include the viewer version or commit, operating-system and Node/npm versions, redacted error code and a minimal reproduction containing no customer evidence, credentials or private keys.

Security vulnerabilities must follow `SECURITY.md`, not a public issue.

Glare•9 may separately offer paid consultancy, integration, deployment, training, assurance reviews, maintenance and bespoke development. The open-source licence does not include a service-level agreement, warranty or entitlement to private support. Contact [hello@glare9.com](mailto:hello@glare9.com) for commercial enquiries.
